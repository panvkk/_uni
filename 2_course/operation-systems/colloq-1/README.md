# Коллоквиум 1 ОС

Это решение для первого коллоквиума по курсу Операционные системы.
Разработано как REST-сервис с использованием Kotlin и Spring Boot.

## Задачи

1. **Fibonacci**: На вход натуральное число `n`. На выход контейнер с первыми `n` числами Фибоначчи.
2. **Palindrome**: На вход число. На выход — ответ, является ли число палиндромом.
3. **Reverse List**: Развернуть связный список, используя итеративный подход.

## Сборка и тестирование

Для сборки и запуска проекта вам понадобится установленная JDK 17 или выше.

1. **Сборка проекта**:
   ```bash
   ./gradlew build

2. **Запуск тестов**:
   ```bash
    ./gradlew test

3. **Запуск сервиса**:
   ```bash
    ./gradlew bootRun
