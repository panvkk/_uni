# Коллоквиум 2 ОС

Это продвинутое решение для управления списком задач (To-Do List).
Разработано как распределенный REST-сервис с использованием Kotlin и Spring Boot.

## Технологии

**База данных**: Использование PostgreSQL для надежного хранения всех задач.

**Кэширование**: Интеграция Redis для ускорения доступа к данным и снижения нагрузки.

**Очереди сообщений**: RabbitMQ для обработки событий создания и удаления задач.

**Отказоустойчивость**: Resilience4j Circuit Breaker для защиты системы от сбоев БД.

##Сборка и тестирование

Для сборки и запуска проекта вам понадобится установленная JDK 17 или выше и Docker Desktop.

1. **Запуск инфраструктуры**:
   ```bash
    docker-compose up -d

2. **Сборка проекта**:
   ```bash
   ./gradlew build

3. **Запуск тестов**:
   ```bash
    ./gradlew test

4. **Запуск сервиса**:
   ```bash
    ./gradlew bootRun
